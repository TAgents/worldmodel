How to export

Use GitHub's REST workflow-runs response, including total_count and workflow_runs. Paginated responses can be wrapped in an array. The export must contain every run reported by total_count. Keep the chosen repository, branch, event, and time range consistent with the source query.

gh api --paginate --slurp \
  'repos/OWNER/REPO/actions/runs?per_page=100' \
  > workflow-runs.json

The application reads the file you supply. It does not connect to GitHub or request credentials.

Each reading summarizes a closed window: any completed failure or timeout is true; only an all-success window is false. Missing, cancelled, skipped, or unfinished data does not establish success. Windows use the source's updated_at timestamp, preserved with each contributing run.
